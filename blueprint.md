# Perfumeria App Blueprint

## Overview

This document outlines the architecture and implementation details of the Perfumeria App, a Flutter application designed for managing a perfume inventory. The app uses Firebase for backend services, including authentication and a real-time database with Cloud Firestore.

## Implemented Features

*   **Firebase Authentication:** Secure user login.
*   **Firestore Database:** Real-time data storage for the perfume inventory.
*   **CRUD Operations:** Full functionality to create, read, update, and delete perfumes.
*   **UI Enhancements:**
    *   Action buttons (View, Edit, Delete) for each product.
    *   A dedicated details screen for viewing perfume information.
